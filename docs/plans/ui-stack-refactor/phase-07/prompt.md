## Invariants & Boundaries
- No `cmdk`, no Radix, no new runtime dependencies. Commands that need a document are shown disabled, never hidden.
- Shortcuts and palette items call the same `commands.ts` command as the toolbar. Pickers (`showOpenFilePicker`, `showDirectoryPicker`) open synchronously from the user gesture: the Cmd+O keydown handler and the palette item's select handler must reach the picker with no `await`, animation, or state round-trip first. If closing the palette must precede the picker, call the command first, in the same handler.
- Shortcuts do not fire while typing in the Open URL dialog input or other text inputs; Cmd/Ctrl+S works inside the CodeMirror editor. Ignore `isComposing` keydown events. Use `preventDefault` for handled shortcuts.
- Palette keyboard model: arrow keys move highlight, Enter runs the highlighted item, Escape closes and returns focus to the element focused before opening; focus is trapped while open.
- Race protocol, `onEdit` to `viewRef.update` bypassing React state, render pipeline and DOMPurify, storage keys and formats, lazy Shiki/KaTeX/Mermaid, dark mode, export, toasts, status banners all unchanged. S3 and S4 gates hold. Avoid new whole-store subscriptions; select the fields you need.
- Out of Scope: motion polish, reduced motion, contrast audit, Biome rule restoration (Phase 8).
