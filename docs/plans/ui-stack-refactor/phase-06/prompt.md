## Invariants & Boundaries
- Every v1 action stays reachable. Pickers (`showOpenFilePicker`, `showDirectoryPicker`) open synchronously from the user gesture: no `await`, animation, or state round-trip before the picker call.
- Save conflict stays a dialog. Dismissing an error never clears the external-change prompt. Dirty state has a visible dot and screen-reader text "Unsaved changes".
- Open URL dialog uses a native `<form>` and the `src/lib/schemas.ts` URL check reusing `isAllowedUrl`, so `file:` stays allowed. No React Hook Form, no Motion, no cmdk.
- Race protocol (generation counter, `isCurrent()`, source identity checks, saves pinned to committed path), `onEdit` to `viewRef.update` bypassing React state, render pipeline and DOMPurify, storage keys and formats, lazy Shiki/KaTeX/Mermaid, dark mode, export (zero network, no script) all unchanged. - Accessible names of existing actions stay stable where the action survives (tests use role-based selectors); renamed or relocated controls must be reflected in tests without weakening assertions.
- Out of Scope: command palette, keyboard shortcuts (Cmd+K/S/O/\/P), motion polish (Phase 8). The palette button may exist but can be disabled or a no-op placeholder clearly labeled for Phase 7; record the choice.
