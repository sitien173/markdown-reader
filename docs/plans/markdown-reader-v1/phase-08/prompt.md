Implement progressive rendering for large documents: render and sanitize the first blocks that fill the viewport first, then append the remaining sanitized blocks in idle or timer chunks, aborted by the source-generation guard on source change. Every block passes the sanitizer. TOC headings must be complete once rendering finishes. S4 in `perf.spec.ts` is asserted as: first document content visible within 500 ms of render start for a 1 MiB fixture. - S3: re-assert in `perf.spec.ts` as keystroke to updated preview DOM on the 100 KB fixture, median under 100 ms. If parsing the whole document blocks this, parse only changed blocks. If end-to-end still fails under host load, report the measured medians with load average; do not silently loosen the threshold.
