**Short Description** [REQUIRED] (132 characters max)

**Detailed Description** [REQUIRED] (16,000 characters max)
Markdown Reader turns plain Markdown files into clear, well-formatted pages, right in your browser.

Open a Markdown file from your computer, a folder full of notes, or any web address that ends in .md or .markdown. Headings, tables, code with syntax colors, math formulas, and diagrams all appear as the author intended. A contents panel lists every section, so you can jump straight to the part you need.

Edit as you read. Split view shows your Markdown next to a live preview, so changes appear as you type. Save your changes back to the file on your computer, or keep a draft that is kept safely in your browser until you save it. If a file changes on disk, the reader can show the latest version. Open a whole folder to browse its Markdown files in a sidebar tree.

Share or keep a finished page. Export a document as a single HTML file that opens anywhere with no internet connection and looks the same. Print a document, or save it as a PDF from the print dialog, with the reader controls left out.

To get started, click the Markdown Reader toolbar icon and choose Open viewer, or right-click a link to a Markdown file and choose Open in Markdown Reader. To open a file on your computer, use Open file in the reader or drag the file onto the page. To read Markdown files stored on your computer by their address, turn on "Allow access to file URLs" in the extension's details page at chrome://extensions. Optional.

Your documents stay on your device. Markdown Reader does not send your documents, drafts, file names, or browsing activity to any server. See the privacy policy for details.

## Permissions Justification

Every permission in `manifest.json` and the file-access setting need a specific reason. Each reason names the feature that uses it.

| Permission | Type | Justification |
|------------|------|---------------|
| `storage` | permissions | Keeps the user's work on the device between sessions: unsaved editor drafts in `chrome.storage.local` so they survive a closed tab, the list of recently opened documents, and a short-lived handoff of Markdown text from a `.md` page to the reader tab in `chrome.storage.session`. No data leaves the device. |
| `contextMenus` | permissions | Adds the "Open in Markdown Reader" item to the right-click menu on links, so a user can open a linked Markdown file in the reader without copying its address. |
| `tabs` | permissions | Reads the address of the current tab so the toolbar popup can offer "Render current tab" for the page the user is viewing, opens the reader in a new tab, and redirects a raw Markdown page to the reader in the same tab. Without it, the current tab's address cannot be read. |
| `<all_urls>` | host_permissions | Lets the reader fetch a Markdown file from any web address the user chooses to open or types into the address field, and lets the content script check whether the page the user is viewing is a raw Markdown document (`.md` or `.markdown`) so it can show the reader. The extension reads only the raw text of those documents and does not read, change, or send other pages. |
| File URL access (user-enabled) | Not a manifest permission | Chrome does not grant file access by default. The user turns on "Allow access to file URLs" in chrome://extensions. It lets the reader show a Markdown file opened by its `file://` address, and auto-reload it when it changes on disk. The extension does not work with other local files. The first-run guidance explains how to turn it on. |

Local folder and file access through the browser's file picker (for opening, folder browsing, and saving changes) is granted by the user for each selection and does not need a manifest permission.

## Privacy & Data Use

### Data Collection

**Does the extension collect user data?** No

The extension does not collect, transmit, sell, or share user data. Documents, drafts, file names, recent-document lists, and folder permissions stay in the browser on the user's device. The extension has no analytics and no accounts.

## Review Notes

### Known Issues / Limitations
- Some features depend on the browser's file access: folder browsing and save-back use the file picker, and reading `file://` addresses requires the user to enable file URL access.
- Diagrams and math in an exported HTML file are rendered when the file is created and do not need the internet to open.
- Before the first submission, this file, the privacy policy, and the README's build steps must be checked against the release build.
