# Privacy Policy — Markdown Reader

Last updated: [YYYY-MM-DD]

Markdown Reader is a Chrome extension that displays, edits, and exports Markdown documents.

## Your documents stay on your device

Opening a web document requests that URL, including path and query, from its server; remote images a document references are loaded from their hosts. Otherwise documents stay on the device.

## What is stored on your device

The extension keeps the following only in your browser's storage on your device:

- Unsaved editor drafts, so your work survives a closed tab. A draft is deleted when you save the file or remove it.
- A list of recently opened documents, so you can reopen them.
- Permission to access a file or folder that you selected through the browser's file picker. Removing the extension deletes these stored items.
- A short-lived copy of Markdown text, held in the session storage of your browser while a document opens in the reader. The reader removes it once it has read the copy, and the browser clears session storage when it closes.

## Web addresses you open

Opening a web document requests that URL, including path and query, from its server; remote images a document references are loaded from their hosts. Otherwise documents stay on the device.

## Local files

Files you open from your computer are read on your device. When you choose to save changes, the extension writes them back to the same file on your device. When you choose to export, it creates an HTML file on your device.

## Permissions

The extension asks for the following browser permissions. Each one is used only for the feature described here.

- **Storage**: keeps drafts, the recent-documents list, and the short-lived handoff described above, on your device.
- **Context menus**: adds "Open in Markdown Reader" to the menu that appears when you right-click a link.
- **Tabs**: reads the address of the current tab when you choose "Render current tab", opens the reader in a tab, and moves a raw Markdown page to the reader.
- **Access to all sites**: lets the reader load a Markdown document from a web address you open, and lets it recognize raw `.md` and `.markdown` pages. It does not read or change other pages.
- **File URL access** (turned on by you in the extension settings): lets the reader display Markdown files opened by their `file://` address.

## Children's privacy

Markdown Reader does not knowingly collect any information from anyone, including children.
