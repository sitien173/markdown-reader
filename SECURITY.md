# Security Policy

## Supported Versions

Only the latest release receives security updates.

| Version  | Supported |
| -------- | --------- |
| Latest   | Yes       |
| < Latest | No        |

## Reporting a Vulnerability

Report security vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/sitien173/markdown-reader/security/advisories/new).

Do not report security vulnerabilities in public issues or discussions.
